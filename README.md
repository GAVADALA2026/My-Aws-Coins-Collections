# MyAwsCoinsCollection

MyAwsCoinsCollection is a teaching app created for the seminar of the `Web Technologies` course at the Università degli Studi di Salerno.

The application is a small Angular project focused on a coin collection experience with a fake login flow used only for demo purposes.

> Note: the login is not real. You can enter any username and any password to access the app.

## Live deployment

The application is published through GitHub Pages:

- https://gavadala2026.github.io/My-Aws-Coins-Collections/

The GitHub Pages workflow builds the production application with the base URL
`https://gavadala2026.github.io/My-Aws-Coins-Collections/` and publishes the
artifact generated in `dist/my-aws-coins-collection/browser`.

## Technology stack

- Angular `21.2.22`
- Angular Material `21.2.14`
- NgRx Store and Effects `21.1.0`
- RxJS `7.8.2`
- Tailwind CSS `4.2.2`
- Node.js `24.15.0` (declared in `.nvmrc`)
- Jest `30.4.2` with `jest-preset-angular`
- Playwright `1.62.1` for Chromium E2E coverage

## How to run

Set your Node environment:

```bash
nvm use
```

Install the exact dependency tree recorded in the lockfile:

```bash
npm ci
```

Start the development server:

```bash
npm run start
```

The app will be available at `http://localhost:4200/`.

### Dependency-security remediation

Issue [#7](https://github.com/GAVADALA2026/My-Aws-Coins-Collections/issues/7)
started from an `npm audit` result of 29 findings: 1 critical, 20 high,
5 moderate and 3 low. The compatible Angular 21 patch updates and transitive
lockfile updates were reviewed and applied without `--force` or
`--legacy-peer-deps`.

Final verification after `npm ci`:

```text
npm audit: 0 vulnerabilities
```

The remediation updates the Angular framework and build toolchain to the
secure `21.2.22` patch line, refreshes vulnerable transitive packages (including
`tar`, `undici`, `vite`, `piscina`, `postcss` and `esbuild`) and keeps the
lockfile reproducible. Informational npm deprecation notices are not audit
vulnerabilities and remain outside this security finding count.

### Deferred dependency maintenance

The 2026-08-30 dependency review found no `npm audit` vulnerabilities and no
safe non-major update outside the ranges already recorded in the lockfile.
`@angular/animations@21.2.22` emits an Angular deprecation notice; removing it
requires a product migration to `animate.enter`/`animate.leave`, so it is
deferred rather than changed as maintenance. The remaining `glob` and
`inflight` notices are transitive test-toolchain dependencies
(`jest-preset-angular` → `ts-jest` → `test-exclude`) and have no compatible
direct replacement in the current dependency graph. They are deprecation
notices, not audit findings.
